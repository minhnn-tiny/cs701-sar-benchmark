# CS701 Team 5: final report (CVPR 2027 template)

- Build: `latexmk -pdf main.tex` (or import this folder into Overleaf; `main.tex` is the root). 6 pages with references.
- Our text is in `sec/0_abstract.tex` to `sec/5_conclusion.tex`; `main.bib` holds our references. The template's own
  sections (`sec/2_formatting.tex`, `sec/3_finalcopy.tex`, `sec/X_suppl.tex`, `rebuttal.tex`) are not used.
- Figures in `figs/`: `pipeline.tex` (TikZ, drawn in LaTeX), and charts and examples generated by `../scripts/`
  (`qualitative.py`, `thumbs.py` and `per_class.py` run the models through `workspace/gpu_run.sh`; `charts.py` reads
  their output and the runs' `decode_lab.json`). Every number traces to `workspace/mtdet/EXPERIMENTS.md`,
  `workspace/mtdet/submissions/SUBMISSIONS.md` or those files.
