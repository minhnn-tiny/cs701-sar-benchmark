(~60 s) Our second addition uses the coupling of the tasks, at inference and for free. First, detector to class: if the detector finds a very confident oil tank, the image is probably an oil-tank scene, so we add the log of the best box score per class to the classifier’s log-probability. Second, class to detector: COCO AP ranks all boxes of a class across all images, so a box in an image that is unlikely to be of that class should rank lower; we multiply box scores by the class probability to the power one half. Together this gained 0.61 on the holdout, winning on all nine runs, and 0.28 on val, with no new parameters. Finally, stochastic weight averaging added a little more. Interestingly, averaging separately trained seeds destroys the model: they sit in different basins.
